# TruckHub 🚛

**Seu computador de bordo inteligente para ETS2.**

Projeto em desenvolvimento — V1 focada no motorista individual de Euro Truck Simulator 2.

## Visão geral

O TruckHub será composto por:

- Site oficial
- Painel web pessoal do motorista
- Aplicativo Windows com tablet/overlay
- Conector com a telemetria do ETS2
- API/backend
- Banco PostgreSQL
- Sistema de teste grátis por 7 dias
- Licença vitalícia após compra
- Integração com Mercado Pago
- Atualizações automáticas

## Desenvolvimento

A infraestrutura inicial será mantida em serviços gratuitos durante a fase de testes. Custos pagos serão adicionados somente quando o projeto começar a gerar receita e houver necessidade de escala.

O desenvolvimento será incremental: cada etapa importante será publicada no GitHub em um commit próprio e testada antes da próxima etapa.
