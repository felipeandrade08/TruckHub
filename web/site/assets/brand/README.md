# Identidade visual TransPoli • TruckHub

Arquivos oficiais da marca. A documentação completa está em `docs/BRAND.md`.

| Arquivo | Uso |
|---|---|
| `transpoli-logo.png` | Logo oficial com fundo transparente (1024×1024) |
| `transpoli-bg.jpg` | Fundo oficial (site + app) |
| `transpoli-bg-mobile.jpg` | Fundo otimizado para celular |
| `icons/favicon.ico` | Favicon do site |
| `icons/transpoli.ico` | Ícone do executável Windows |
| `icons/icon-*.png` | Ícones PNG (16 a 512) |
| `icons/apple-touch-icon.png` | iOS |
| `icons/maskable-*.png` | Android / PWA |
| `truckhub-badge.png` | Alias legado da logo |

Os ícones são gerados a partir de `transpoli-logo.png`. Ao trocar a logo, regere todos os tamanhos.
